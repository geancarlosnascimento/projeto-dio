# Projeto-GAPInvestimentos

As perguntas que a ferramenta responde, e onde aparece cada resposta: 
A aplicação dispõe de informações como sugestão de investimento baseado em 30% do salário, o qual o cliente apenas poderá preencher o campo Salário, em seguida também poderá preencher o campo do Valor que dispõe para investir mensalmente e por quantos anos, e logo será apresentado o valor do Patrimônio acumulado ao final do período e o respectivo dividendo mensal. Abaixo, apresentamos outros cenários com determinados períodos de investimento, o perfil do cliente e o percentual sugerido para cada aplicação. 

Como o VF e o PROCV entram nos cálculos: 
Utilizamos VF para o cálculo do patrimônio acumulado e para apresentar os diversos cenários. Já o PROCV para apresentar de forma automática o perfil do cliente e as sugestões de percentuais para cada tipo de investimento. 

Os intervalos nomeados que você criou:
Para facilitar a construção da aplicação foi utilizada a renomeação da célula para o nome correspondente a cada cálculo gerado.

Os percentuais de cada perfil, e de onde vieram:
Foi criada uma nova planilha, a qual utilizamos o PROCV para apresentar o perfil e os percentuais sugeridos para cada investimento de forma automática, baseada em cada perfil.

O que você mudou em relação à ferramenta do Expert:
A otimização e automação nos cálculos necessários para a tomada de decisão.
